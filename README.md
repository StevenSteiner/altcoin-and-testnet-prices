# AltQuick testnet kit and market pages

Public info site for [AltQuick](https://altquick.com): guides for buying Bitcoin signet, testnet4 and testnet3 coins, why testnet coin markets exist, a developer guide, a press kit, a live page for every market and monthly reports.

The live numbers come from AltQuick's public API ([docs](https://github.com/AltQuick-com/api)). Monthly reports live in `data/report-YYYY-MM.json`.

Build: `python3 scripts/build.py` (standard library only). The built site is in `docs/`, served by GitHub Pages.
